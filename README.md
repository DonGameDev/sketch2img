# Sketch-to-Image Generator

This repository contains a powerful, real-time AI sketch-to-image generator. The application is built with Python and Gradio, and it uses the Hugging Face API to perform image generation.

It has been enhanced with a suite of advanced features, including:
*   **Multiple Modes:** Supports sketch-to-image, image-to-image, and inpainting.
*   **Advanced Controls:** Fine-tune your creations with negative prompts, guidance scale, and a seed for reproducible results.
*   **Image History:** A gallery keeps track of your recent creations in the current session.
*   **Refined UI:** A clean, tabbed interface for a smooth user experience.
